# Green Pulse AI 문서

## 현재 기준

- 1단계: HGB가 매분 결함 확률을 출력하고 경보 규칙이 incident를 생성한다.
- 2단계: 경보 이후 온라인 Extra Trees가 F1~F4 확률을 매분 갱신한다.
- 상태: 합성 데이터와 35개 이벤트로 만든 prototype이며 외부 검증 전 배포하지 않는다.
- 오탐 단위: 별도 표기가 없으면 반응기 1대·24시간당 경보 에피소드다.
