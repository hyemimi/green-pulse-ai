# 화학공정 시계열 데이터셋 분석

## 1. 데이터셋 개요

본 데이터셋은 연속식 화학 반응기의 운전 환경을 시뮬레이션하여 생성한 **합성 다변량 시계열 데이터(Synthetic Multivariate Time-Series Data)**이다.

산업 현장의 센서 측정값, 공정 제어 특성, 운전 조건별 차이 및 점진적인 결함 발생 과정을 모사하였으며, 공정 이상 탐지, 결함 유형 분류, 설비 고장 예측 등의 머신러닝 연구를 목적으로 한다.

| 항목 | 내용 |
|---|---|
| 데이터 유형 | 다변량 시계열 데이터 |
| 측정 주기 | 1분 |
| 수집 기간 | 약 180일(데이터셋 설명 기준) |
| 반응기 수 | 6개(데이터 미리보기 기준) |
| 운전 조건 | 2개(A, B) |
| 결함 유형 | 정상 1개, 결함 4개 |
| 결측치 비율 | 약 6% |
| 데이터 생성 방식 | 규칙 기반 화학공정 시뮬레이션 |
| 라이선스 | CC0(Public Domain) |

**참고:** 데이터셋 설명에는 약 26만 건, 약 180일의 데이터가 명시되어 있으나, 제공된 데이터 미리보기에서는 2024년 1월 1일부터 3월 31일까지의 기간이 확인된다. 정확한 데이터 규모와 수집 기간은 원본 CSV 파일을 기준으로 검증할 필요가 있다.

## 2. 운전 조건 (Operating Regime)

데이터셋은 서로 다른 생산 환경을 반영하기 위해 두 가지 운전 조건으로 구성되어 있다.

| 구분 | Regime A: 기준 운전 | Regime B: 고부하 운전 |
|---|---|---|
| 온도 및 압력 | 기준 수준 | 상대적으로 높은 수준 |
| 냉각 효율 | 높음 | 상대적으로 낮음 |
| 센서 노이즈 | 상대적으로 적음 | 상대적으로 많음 |
| 결함 발생 확률 | 낮음 | 높음 |
| 운전 특성 | 안정적인 장기 운전 환경 | 가혹하거나 높은 생산 부하의 운전 환경 |

Regime A는 안정적인 기준 운전 환경을, Regime B는 온도와 압력이 높고 냉각 효율이 상대적으로 낮은 고부하 운전 환경을 나타낸다.

**운전 조건과 결함 상태는 구분하여 해석해야 한다.** Regime B는 고부하 운전 환경을 의미하며, 반드시 결함이 발생한 상태를 나타내는 것은 아니다. 실제 결함 여부 및 유형은 `fault_type` 컬럼을 통해 확인한다.

## 3. 결함 유형 (Fault Type)

데이터셋은 정상 상태와 네 가지 결함 유형을 포함하며, 각 결함은 시간 경과에 따라 점진적으로 발생하도록 설계되어 있다.

| 코드 | 결함 유형 | 설명 |
|---|---|---|
| 0 | Normal Operation | 정상 운전 상태 |
| 1 | Cooling System Degradation | 냉각 시스템의 성능 저하 |
| 2 | Feed Flow Blockage | 원료 공급 유로의 막힘 또는 유량 저하 |
| 3 | Sensor Drift | 센서 측정값의 점진적인 편향 |
| 4 | Mechanical Wear | 기계 부품의 마모 및 성능 저하 |

특히 **결함 유형 3(F3)은 열폭주가 아닌 센서 드리프트(Sensor Drift)**로 정의되어 있다.

센서 드리프트는 센서의 측정값이 시간 경과에 따라 실제 측정 대상의 값에서 점진적으로 벗어나는 현상이다. 이러한 편향은 공정 상태를 부정확하게 판단하는 원인이 될 수 있다.

데이터셋의 결함은 순간적으로 발생하기보다 점진적으로 발전하며, 결함 발생 이전부터 센서 측정값의 변화 및 변동성 증가가 나타날 수 있도록 구성되어 있다.

또한 실제 산업 환경의 특성을 반영하기 위해 정상 및 결함 클래스 간 데이터 불균형이 존재한다.

## 4. 데이터 컬럼 구성

데이터셋은 총 21개 컬럼으로 구성되며, 식별 정보, 환경 변수, 센서 측정값, 공정 성능, 제어 변수 및 예측 대상으로 구분할 수 있다.

### 4.1. 식별 정보 및 환경 변수

| 컬럼명 | 설명 |
|---|---|
| `timestamp` | 센서 데이터 측정 시각 |
| `operating_regime` | 운전 조건 구분(A/B) |
| `reactor_id` | 반응기별 고유 식별자 |
| `ambient_temp_effect` | 외부 온도의 계절적 변화가 공정에 미치는 영향 |

### 4.2. 주요 공정 센서

| 컬럼명 | 설명 |
|---|---|
| `reactor_temp` | 반응기 내부 온도 |
| `reactor_pressure` | 반응기 내부 압력 |
| `feed_flow_rate` | 반응기로 유입되는 원료의 유량 |
| `coolant_flow_rate` | 냉각 유체의 유량 |
| `agitator_speed_rpm` | 교반기의 분당 회전 속도(RPM) |

### 4.3. 공정 성능 지표

| 컬럼명 | 설명 |
|---|---|
| `reaction_rate` | 화학 반응 진행 속도 |
| `conversion_rate` | 투입 원료가 생성물로 전환된 비율 |
| `selectivity` | 원하는 생성물이 생성되는 비율을 나타내는 선택도 |
| `yield_pct` | 전체 공정의 수율(%) |

### 4.4. 기계 및 전기 센서

| 컬럼명 | 설명 |
|---|---|
| `vibration_rms` | 진동 신호의 실효값(RMS) |
| `motor_current` | 모터의 전류 측정값 |
| `power_consumption_kw` | 설비의 전력 소비량(kW) |

### 4.5. 공정 제어 변수

| 컬럼명 | 설명 |
|---|---|
| `temp_setpoint` | 제어 시스템에서 설정한 목표 온도 |
| `pressure_setpoint` | 제어 시스템에서 설정한 목표 압력 |

### 4.6. 예측 대상 변수

| 컬럼명 | 설명 |
|---|---|
| `fault_type` | 정상 및 결함 유형을 나타내는 클래스 레이블(0~4) |
| `efficiency_loss_pct` | 공정 효율 감소율(%) |
| `time_to_fault_min` | 결함 발생 시점까지 남은 시간(분) |

## 5. 머신러닝 활용 방안

본 데이터셋은 다양한 공정 센서의 시계열 특성과 결함 레이블을 포함하고 있어, 이상 탐지부터 결함 진단 및 고장 예측까지 여러 머신러닝 과제에 활용할 수 있다.

| 분석 과제 | 주요 입력 데이터 | 예측 대상 |
|---|---|---|
| 이상 탐지(Anomaly Detection) | 온도, 압력, 유량 등 센서 데이터 | 정상 및 이상 상태 |
| 결함 분류(Fault Classification) | 다변량 센서 데이터 및 파생 특징 | 결함 유형(0~4) |
| 효율 저하 예측(Regression) | 센서 및 공정 성능 데이터 | 공정 효율 감소율 |
| 고장 시점 예측(Fault Prognostics) | 과거 센서 시계열 데이터 | 결함 발생까지 남은 시간 |

예를 들어 반응기 온도가 상승하는 동시에 냉각수 유량이 감소하는 패턴이 관찰될 경우, 냉각 시스템 성능 저하(F1)의 징후로 활용할 수 있다.

다만 이는 공정 특성에 기반한 가설이며, 실제 데이터에서 해당 변수와 결함 간의 연관성이 존재하는지는 탐색적 데이터 분석(EDA)을 통해 검증해야 한다.

## 6. 데이터 분석 및 모델링 시 고려사항

### 6.1. 결측치 처리

전체 데이터에는 약 6%의 결측치가 포함되어 있으며, 이는 실제 산업 현장에서 발생할 수 있는 센서 데이터 누락을 모사한 것이다.

결측치의 발생 위치와 지속 시간을 분석한 후 선형 보간, 이전 값 대체 또는 모델 기반 결측치 추정 등의 처리 방법을 검토할 필요가 있다.

### 6.2. 운전 조건별 데이터 분포 차이

Regime A와 Regime B는 온도, 압력, 냉각 효율 및 센서 노이즈 특성이 서로 다르다.

따라서 모든 운전 조건에 동일한 정상 범위나 이상 탐지 임계값을 적용할 경우 오탐 또는 미탐이 발생할 수 있다.

운전 조건별 데이터 분포를 분석하고, 필요에 따라 조건별 정규화 또는 모델 분리 전략을 검토할 필요가 있다.

### 6.3. 시계열 데이터 분할

시계열 데이터는 시간적 연속성과 자기상관성을 가지므로, 무작위 분할 시 학습 데이터와 평가 데이터 간 정보 누출이 발생할 가능성이 있다.

이를 방지하기 위해 시간 순서를 고려하여 학습·검증·테스트 데이터를 분리하고, 분석 목적에 따라 반응기 단위의 일반화 성능도 함께 평가할 필요가 있다.

### 6.4. 데이터 누출 방지

`fault_type`, `efficiency_loss_pct`, `time_to_fault_min`은 데이터셋에서 예측 대상으로 정의된 컬럼이다.

특히 결함 유형 분류 모델을 학습할 경우, 예측 시점에 실제로 확보할 수 없는 정답 정보가 입력 변수에 포함되지 않도록 주의해야 한다.

또한 시계열 특징 생성 과정에서 미래 시점의 데이터가 사용되지 않도록 관리해야 한다.

### 6.5. 합성 데이터의 한계

본 데이터셋은 실제 화학공장에서 수집된 데이터가 아닌 규칙 기반 시뮬레이션 데이터이다.

따라서 모델의 성능이 우수하더라도 이를 실제 산업 환경에서의 성능으로 일반화하기는 어렵다.

실제 현장 적용을 위해서는 실측 데이터 기반의 추가 검증과 운전 환경 변화에 대한 강건성 평가가 필요하다.

## 7. 종합 분석

본 데이터셋은 다양한 운전 조건과 점진적인 결함 발생 특성을 포함하고 있어, **다변량 시계열 기반의 공정 이상 탐지 및 결함 진단 모델을 개발하고 평가하는 데 활용할 수 있다.**

특히 개별 센서의 임계값 초과 여부뿐 아니라, 시간에 따른 센서 변화량과 여러 변수 간의 관계를 분석하는 접근이 중요하다.

이를 위해 누적합(CUSUM) 기반 이상 후보 탐지와 로지스틱 회귀 기반 결함 분류를 결합하는 방법을 검토할 수 있다.

모델 성능 평가 시에는 분류 정확도뿐 아니라 결함별 탐지율, 오탐 발생 빈도, 결함 발생 이후 탐지까지 소요된 시간 등을 함께 고려하는 것이 적절하다.

궁극적으로 본 데이터셋을 활용한 분석의 목표는 **결함의 조기 탐지와 정확한 유형 분류를 수행하면서 오탐을 최소화할 수 있는 이상 탐지 체계를 설계하고 검증하는 것**이다.
